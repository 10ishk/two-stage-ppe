# Contributing

Thank you for improving two-stage-ppe.

1. Open an issue for substantial behavior or API changes.
2. Create a focused branch and keep changes small.
3. Add or update weight-free tests.
4. Run `python -m pip install -e ".[test]"` and `pytest`.
5. Do not commit datasets, images, checkpoints, credentials, or private paths.
6. Explain user-visible changes and tradeoffs in the pull request.

Contributions must follow the Code of Conduct and be compatible with Apache-2.0 distribution.
