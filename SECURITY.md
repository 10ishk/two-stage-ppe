# Security policy

## Supported version

Security fixes currently target the latest `0.1.x` release line.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting when available. Otherwise contact the repository owner privately through their GitHub profile. Do not open a public issue for an unpatched vulnerability.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid attaching proprietary datasets or checkpoints. You should receive an initial response within seven days.
